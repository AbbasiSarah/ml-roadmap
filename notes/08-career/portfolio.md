# GitHub portfolio

*Portfolio & Career* · [Open in the interactive roadmap](https://abbasisarah.github.io/roadmap/#portfolio)

> **In one sentence:** A portfolio is 3–5 projects that show you can solve real problems end to end and explain them clearly.

## Key ideas
- Each README: problem → data → method → result in numbers → chart → how to run → limitations.
- Show judgement: baselines, honest evaluation, what didn't work.
- A live demo link gets clicked far more than code.
- Pin your best repositories; add topics and descriptions.

## Example
```markdown
## Results
| Model | Precision | Recall | F1 |
|---|---|---|---|
| Baseline (always "ham") | 0% | 0% | 0.00 |
| **Linear SVM** | **99.2%** | **94.7%** | **0.969** |

Try it: `python predict.py "WINNER!! Claim your prize"`
```

## Common mistakes
- Copying tutorial projects (Titanic, Iris) with no twist.
- No README or results; recruiters won't run your code.
