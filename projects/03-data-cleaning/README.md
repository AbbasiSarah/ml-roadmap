# Clean a messy dataset, with a log

*Stage 3 · Data Skills* · [All projects](../../README.md#projects)

320 messy student records: duplicates, 'lhr'/'KHI' city spellings, ages of 250, marks like '75%' or 'absent'. The script fixes each problem and writes a cleaning log.

## Run it
```bash
python make_messy.py
python clean.py
```

## What you practise
Deduplication, standardising text, impossible values, missing-value flags.
