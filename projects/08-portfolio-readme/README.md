# Stage 8 project: a README that gets your project noticed

Recruiters spend under a minute on a repository. Use [README_TEMPLATE.md](README_TEMPLATE.md) for every project:
the result in numbers first, a chart, how you tested, and how to run it.

Real examples that follow this template:
- [California House Prices](https://github.com/AbbasiSarah/california-house-prices)
- [SMS Spam Classifier](https://github.com/AbbasiSarah/sms-spam-classifier)
- [Handwritten Digit CNN](https://github.com/AbbasiSarah/handwritten-digit-cnn)
- [Depression detection research](https://github.com/AbbasiSarah/depression-bipolar_CNN)

**Your task:** pick your best project and rewrite its README with this template. Then pin it on your GitHub profile.
